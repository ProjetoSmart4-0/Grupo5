### Classificação dos resultados

- PASS: atividade validada com sucesso.
- PASS WITH LIMITATION: atividade validada com limitações registradas.
- BLOCKED: atividade impedida por uma dependência ou bloqueio.
- FAIL: atividade executada sem atingir o resultado esperado.

### Regras de segurança

Nenhum token, segredo ou credencial deverá ser incluído nas evidências.

Cada teste deverá conter data, hora, versão, resultado esperado e resultado obtido.

A escrita nos CLPs depende de autorização formal do responsável pela automação.
